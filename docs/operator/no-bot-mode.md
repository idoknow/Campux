# 无 Bot 模式运营

无 Bot 模式（`operate_mode = manual`）指**不接入任何 QQ 机器人**也能开校园墙。稿件审核通过后不会自动发到 QQ 空间，而是停在「待发布」，由管理员在网页端渲染图片、复制文案、手动发出去，再回来确认。

它适合：人手充足、暂时不打算上 NapCat、或机器人账号有风险的小墙。

## 和其它模式的区别

| 能力 | 墙号机器人模式 | 无 Bot 模式 |
| --- | --- | --- |
| 用户进站 | 私聊墙号自动注册 | 只能靠「游客投稿」或「聚合登录自动建号」 |
| 审核通过 | 自动进发布队列 | 停在「待发布」等你手动发 |
| 发布到 QQ 空间 | 程序自动发 | 你手动发，回来点「确认已发布」 |
| 审核群通知 | 有新稿、通过、失败通知 | **没有**，需要自己盯页面 |
| 撤回说说 | 程序设为仅自己可见 | **删不了**，需要手动删除后回来确认 |
| 空间数据（浏览/赞/评论） | 自动同步 | **没有**，没有发帖记录就无法拉取 |
| 评论管理 / 热榜 | 可用 | 不可用 |

::: warning 先开通进站通道
无 Bot 模式没有「私聊墙号自动建号」。如果「游客投稿」和「聚合登录自动建号」都没开，**普通同学根本注册不进来**，管理员也无法代为创建账号（成员管理要求账号已存在）。

在「管理 · 插件配置」里至少开启一项：

- **游客投稿**：同学用 QQ 号 + 用户名 + 密码自己注册；
- **聚合登录** ＋「首次扫码自动建号」：同学用 QQ 扫码直接建号进墙。
:::

### 注册要不要邮箱验证

「管理 · 墙面设置 · 注册与邮箱验证」决定网页注册的门槛：

- **关闭**：填 QQ 号 + 用户名 + 密码即可注册；
- **开启**：还要填邮箱并收验证码，且邮箱后缀必须在允许列表内（列表为空 = 不限制后缀）。

开启前必须先配好发件服务（官方发件或自建 SMTP），并发一封测试邮件确认能收到，否则保存会被拒绝。
注册后同学可以用 QQ 号或邮箱登录，两种方式等价。

详见 [登录与密码接口](/reference/auth-and-password)。

::: tip 切换运营模式会触发「绑定之前的账号」提示
墙从机器人模式切到无 Bot（或反过来）后，还没绑定邮箱的同学下次登录会被询问是否把之前的账号绑定过来。
已绑邮箱或已合并过的账号不会再被询问；跳过了也能随时在「服务 · 账户设置 · 绑定之前的账号」补做。
:::

## 开通方式

两种入口，效果一样：

1. **开墙向导**：在「接入墙号机器人」这一步点「无 Bot 模式运营」。向导会跳过「配置发布到空间」，直接把墙标记为已开通。
2. **切换已有校园墙**：「管理 · 墙面设置 · 发布与通知 · 运营模式」改成「无 Bot 模式运营」。

切换时系统会检查进站通道。没有开通任何通道会拦下并提示；确实要先开墙再补配置时，可以确认「仍然切换」。

切换会写入审计日志：`tenant.operate_mode.update`。

## 每日发布流程

1. **审核**：在「稿件 · 审核」里逐条通过或拒绝。通过后的稿件直接进入「稿件 · 待发布」。
2. **进待发布页**：「稿件 · 待发布」按最早投稿排在前面（可切成最新优先或多图优先）。列表上的数字就是这个墙当前积压量。
3. **准备素材**：
   - 点渲染图可查看大图，「保存图片」直接下载 `campux-post-<编号>.jpg`；
   - 稿件配图的缩略图可直接点开原图另存——手动发说说时要连配图一起发；
   - 「复制文案」按墙面设置里的模板生成说说文案（编号 / 前缀 / 后缀 / @作者），粘贴即可。
4. **发到 QQ 空间**：用墙号 QQ 手动发说说，附上渲染图和原图。
5. **确认**：回到待发布页点「确认已发布」。如果填了「说说链接」，链接会记在这条稿件上，之后在「已发布」里能直接点开对照。

单条确认、勾选多条确认、以及「一键确认全部已发布」都可以用。一键确认前会弹二次确认框，因为**确认只是改状态，系统不会真的把内容发出去**。

## 说说文案模板

「管理 · 墙面设置 · 发布与通知」里的「无 Bot 模式补充设置」：

| 设置 | 作用 |
| --- | --- |
| 墙号 QQ（渲染图角落） | 渲染图右下角显示的墙号；留空用默认头像 |
| 说说文案前缀 | 每条文案最前面固定加一句 |
| 说说文案后缀 | 每条文案最后面固定加一句 |
| 带「#稿件编号」 | 默认开启，方便运营者和作者对号 |
| 实名稿件带「@作者QQ」 | 默认关闭；匿名稿件永远不带 |

## 确认错了怎么办

- **单条确认错了**：「已发布」列表里，手动发布过的稿件会有「退回待发布」按钮，点一下回到待发布队列，可以重新发。
- **一键确认全错了**：目前需要逐条在「已发布」里退回；确认前请务必看清二次确认框里的条数。
- 只有**管理员手动确认**的稿件能退回；自动发布链路产生的已发布稿件不受影响。

## 撤回说说

无 Bot 模式的稿件是你在空间里手发的，系统没有发帖记录（没有 tid），**删不了说说**。

正确做法：

1. 到 QQ 空间手动删除那条说说；
2. 回到「稿件 · 已发布」，找到对应稿件点「已在空间手动删除」；
3. 稿件状态变成「已撤回」。

系统的旧行为是「没有发帖记录就直接标记为已撤回」，导致界面上显示撤回了、空间里其实还在。现在会明确提示需要手动删除。

作者自己申请撤回、审核员同意撤回时也走同一套逻辑：页面会提示「没有可撤回的发布记录」，请手动删除后确认。

## 从机器人模式切过来（bot → manual）

切换后，队列里可能还有正在自动发布的稿件。什么都不做的话它们会继续自动发出去，你又手动发了一遍 → **重复说说**。

所以切到无 Bot 模式后：

1. 到「稿件 · 待发布」顶部，会看到「还有 N 条稿件在自动发布队列里」的提示；
2. 点「停止在途自动发布」，这些稿件会回到待发布，由你手动发；
3. 已经在发送中的那一条停不下来，等它结束后再处理。

系统也会在发布任务真正执行前复查运营模式：墙已经切到 manual 的，队列里的自动发布会被作废，不会偷偷发出去。

## 从无 Bot 模式切回机器人（manual → bot）

切回后，之前积压在待发布的稿件**不会自动进队列**（它们没经过审核入队流程）。需要：

1. 到「稿件 · 待发布」；
2. 顶部会提示「有 N 条审核通过的稿件仍滞留在这里」；
3. 点「一键补入自动发布队列」，按当前发布模式（逐条/批量）入队。

另外，切回机器人后记得把「稿件 · 审核 → 待发布」筛选看一眼是否还有残留。

## 发布文案与渲染图说明

- 渲染图是由服务端渲染的稿件卡片，尺寸和样式与机器人模式一致；角落墙号来自上面的「墙号 QQ」，没有 wall bot 时不显示头像。
- 说说文案里的正文图片**不需要**写进文案，图片是随说说上传的；文案只放编号、前缀/@ 等。

## 运营检查表

- [ ] 「插件配置」里「游客投稿」或「聚合登录自动建号」至少开一项
- [ ] 若要邮箱验证：发件服务已配好并通过测试邮件
- [ ] 渲染图角落 QQ 已填写（或明确不用）
- [ ] 说说文案前缀/后缀符合本墙习惯
- [ ] 「稿件 · 待发布」积压为 0 或每天清一次
- [ ] 从机器人模式切过来时，已停止在途自动发布
- [ ] 切回机器人模式时，滞留稿件已补入队列
