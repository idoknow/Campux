# 指令手册

Campux 的机器人指令分两类：用户在自己的 QQ 里私聊墙号用的**投稿指令**，和审核群管理员在群里用的**审核群指令**。这一页把所有指令和用法列在一起，方便贴在群公告里或发给新成员。

## 书写规则

- 命令前缀 `#`、全角 `＃`、斜杠 `/` 等价，`#通过 12` 和 `＃通过 12` 都能识别。
- 命令词和参数之间要用空格隔开：`#拒绝 图片重复 12`。
- 投稿相关的关键词可以不带前缀，直接发中文（`投稿`、`结束`、`确认`），具体词表由管理员在「管理 → AI 辅助 → 对话投稿关键词」里配置。
- 审核群指令只有本墙成员里的 `reviewer`（审核员）及以上角色可用；用户指令对所有已注册用户开放。
- 审核群指令只在该墙机器人卡片里配置的审核群内生效，其他群里的相同文字会被忽略。

## 用户指令（私聊墙号）

### 投稿

| 指令 | 作用 |
| --- | --- |
| `投稿`、`墙墙`、`墙墙投稿`、`墙`、`吐槽`、`表白` | 开始一次对话投稿。也可以写成 `#投稿 正文` 一次带上第一段正文。 |
| 直接发文字或图片 | 在草稿里追加一段正文或一批图片，不需要任何前缀。 |
| `匿名` / `实名` | 切换本次投稿的方式，默认匿名。默认词表还包括「匿、腻」与「不匿名、不匿、不腻、实」。 |
| `撤回` | 删掉最近追加的一段文字或一批图片，可以连续使用。 |
| `结束`、`完成` | 提交稿件，Campux 会回一条确认提示（确认提示里会写明当前是匿名还是实名）。 |
| `取消`、`算了` | 放弃本次投稿，草稿清空。 |
| `确认`、`可以`、`发`、`发布`、`没问题`、`发吧` | 在确认阶段确认发布。这时候也还能发 `匿名` / `实名` 改投稿方式。 |

正文最多 1000 字，图片最多 9 张，单张图片最大 10MB，和网页投稿一致。

### 管理自己的稿件

| 指令 | 作用 |
| --- | --- |
| `#取消 <稿件编号>` | 取消还在待审核的稿件。 |
| `#撤回 <稿件编号>` | 对已发布的稿件发起撤回申请，审核群会收到通知，审核通过后每个 QZone 发布目标会被设为仅自己可见。 |
| `#撤回 <理由> <稿件编号>` | 同上，并把理由一起发给审核群，例如 `#撤回 发错图了 42`。 |

### 账号

| 指令 | 作用 |
| --- | --- |
| `#注册账号` | 查询是否已拥有本墙账号；首次私聊墙号时系统会自动创建。 |
| `#重置密码` | 生成一个新密码并私信发回，旧密码立即失效。 |

## 审核群指令

### 审核稿件

| 指令 | 作用 |
| --- | --- |
| `#通过 <稿件编号>` | 通过稿件并交给发布队列。引用机器人发来的审核通知再 @机器人，只发「通过」也能定位到那条稿件。 |
| `#全部通过` | 通过当前所有待审核稿件。 |
| `#审核队列`（别名 `#待审核`、`#队列`） | 输出当前待审核队列，按条数分页发送。 |
| `#拒绝 <理由> <稿件编号>` | 拒绝稿件，理由会私信发给作者。同样支持引用审核通知后 @机器人 只发「拒 <理由>」。 |
| `#重发 <稿件编号>` | 把稿件重新加入发布队列，用于发布失败后重试。 |

### 处理撤回申请

| 指令 | 作用 |
| --- | --- |
| `#撤回通过 <稿件编号>` | 同意作者的撤回申请，逐个 QZone 目标设为仅自己可见，并通知作者。 |
| `#撤回拒绝 <理由> <稿件编号>` | 拒绝撤回申请，稿件恢复为已发表，理由会同时发到审核群和作者。 |

撤回申请通知里已经带好这两个指令的写法，也可以引用那条通知再 @机器人 发送。只写编号不写理由时会提示补理由。

### 说说与用户管理

| 指令 | 作用 |
| --- | --- |
| `#发布 <内容>` | 以墙号发布说说这个入口：可以附带图片（最多 9 张），发送后按提示回复 `1` 直接发布、`2` 以墙的身份投稿发布、`3` 取消。 |
| `#撤回 <稿件编号>` 或 `#撤回 <tid>` | 撤回墙号已经发出去的说说；也可以引用机器人的 `#发布` 成功消息再发送 `#撤回`。 |
| `#好友数`（别名 `#好友数量`） | 统计当前墙号的好友数量。 |
| `#封禁 <QQ号> <理由>` 或 `ban <QQ号> <理由>` | 永久封禁指定用户，并私信告知理由。 |
| `#解封 <QQ号>` 或 `unban <QQ号>` | 解除封禁。 |
| `#回复 <内容>` | 仅当本群是「私聊转发群」时可用：引用转发过来的私信消息，再用它回复用户。 |

### 登录与登录态

| 指令 | 作用 |
| --- | --- |
| `#登录`、`#刷新`（别名 `#刷新qzone`、`#刷新cookies`） | 用协议端提供的 cookies 尝试刷新 QZone 登录态。 |
| `#扫码登录`（别名 `#二维码登录`、`#qzone扫码登录`） | 机器人发一张二维码，用该 QQ 手机端扫码登录 QZone。协议端不支持取 cookies 时用这个。 |

### 插件指令

| 指令 | 作用 |
| --- | --- |
| `#毕业通过 <毕业去向编号>`、`#毕业拒绝 <理由> <毕业去向编号>` | 审核毕业去向，需要先启用「毕业去向」插件。 |
| `#投票通过 <竞选编号>`、`#投票拒绝 <理由> <竞选编号>` | 审核竞选，需要先启用「投票竞选」插件。 |

插件关闭时这些指令会被拒绝并提示当前未开启对应插件，帮助文本也不会再列出它们。
