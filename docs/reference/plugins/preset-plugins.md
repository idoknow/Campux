# 预设插件

管理页「插件配置」里内置了一批**租户级预设插件**。它们不需要装 npm 包，开启开关、保存配置即可生效；与通过 PluginRegistry 注册的扩展插件一起出现在左侧列表。

入口：**管理 → 插件配置**。左侧选中插件后，在「配置 / 说明 / 日志」之间切换；改完点「保存配置」。

## 预设 vs 扩展插件

| | 预设插件 | 扩展插件（Registry） |
|---|---|---|
| 来源 | 产品内置，配置存在 `tenant_metadata.plugin_config` | 代码注册进 `PluginRegistry` |
| 启用方式 | 列表开关 → 写 `enabled` | 管理 API / 注册表 `setStatus` |
| 配置界面 | 插件配置页专用面板 | 视插件实现而定 |
| 审计日志 | 配置变更记为 `tenant.plugin.<id>.*` | 注册、状态变更等 runtime 审计 |

日志页可按「当前插件 / 全部插件」筛选；当前插件按 registry 名（如 `campux-plugin-markdown-render`）匹配。

## Markdown 渲染

| 项 | 说明 |
|---|---|
| 标识 | `campux-plugin-markdown-render` |
| 风险 | 低 |
| 作用 | 投稿正文按 Markdown 渲染展示 |

**支持语法**：`**加粗**`、`*斜体*`、`` `代码` ``、`- 列表`、`[链接](url)`、引用等。

**不支持**：表格、自定义 HTML（会被过滤/转义）；图片语法不会渲染为图，请用投稿页的图片上传。

关闭后稿件按纯文本展示。已渲染的历史稿件不会因开关而改变存储内容。

## 多彩投稿

| 项 | 说明 |
|---|---|
| 标识 | `campux-plugin-color-selection` |
| 风险 | 中 |
| 作用 | 为投稿配置背景色 / 文字色预设色板 |

- 背景色、文字色各最多约 10 个预设（名称、标识 value、十六进制色）
- 标识（value）用于落库与前端匹配，**尽量保持稳定**，不要频繁改 value
- 投稿页出现选色入口；稿件墙按预设渲染彩色卡片
- 修改预设后需保存配置；已发布稿件不追溯改色

建议保持至少 3 组可用搭配，并避免对比度过低（如米黄底 + 白字）。

## 字体选择

| 项 | 说明 |
|---|---|
| 标识 | `campux-plugin-font-selection` |
| 风险 | 低 |
| 作用 | 在固定字体库中勾选投稿页可用字体 |

- 字体库随服务端内置，不引入外部字体源
- 默认字体（`default`）为浏览器系统字体，一般建议保留
- 至少启用 1 款；白名单为空时投稿页会隐藏字体入口并提示

修改白名单不追溯已发布稿件。

## 匿名头像

| 项 | 说明 |
|---|---|
| 标识 | `campux-plugin-anonymous-avatar` |
| 风险 | 中 |
| 作用 | 匿名投稿可选头像；支持内置池与自定义 SVG |

- 可从内置 SVG 头像中勾选
- 可粘贴自定义 SVG 源码（注意内容安全，仅建议管理员维护）
- 开启后投稿页在匿名模式下出现头像选择

## Bot 多彩消息

| 项 | 说明 |
|---|---|
| 标识 | `campux-plugin-bot-stylish-messages` |
| 风险 | 低 |
| 作用 | 自定义机器人关键反馈语句（多彩文案） |

常见类型包括：

| 类型 | 场景 | 占位符 |
|---|---|---|
| 投稿成功 | 私聊投稿完成 | `{id}` |
| 审核通过 | 通知作者 | `{id}` |
| 审核拒绝 | 通知作者 | `{id}`、`{reason}` |
| 撤回成功 | 撤回完成 | `{id}` |
| 发布成功 | 已发到墙号 | `{id}`、`{externalId}` |

同一类型可配多条，发送时随机挑选。关闭后使用系统默认文案。

## 投票竞选

| 项 | 说明 |
|---|---|
| 标识 | `campux-plugin-campaigns` |
| 风险 | 中 |
| 作用 | 用户发起竞选/投票，审核通过后在服务页公开 |

- 投稿页出现「发起竞选」入口
- 支持封面/选项图、仅管理可见等开关（视版本配置）
- 经审核群或网页审核通过后，服务页可浏览并投票
- 投票明细、发起人信息会进入租户数据，请按隐私要求运营

## 聚合登录

| 项 | 说明 |
|---|---|
| 标识 | `campux-plugin-aggregate-login` |
| 风险 | 中 |
| 作用 | 绑定第三方身份后，用 QQ / 微信 / 支付宝等登录本墙 |

- **不会自动建号**：未绑定的第三方身份无法直接进入
- 用户需先有本地账号，再到「服务 → 账户设置 → 第三方登录」绑定
- 需配置第三方 AppId / AppKey 等；密钥属租户配置，注意权限
- 登录页会展示已勾选的第三方入口

接口地址等请按聚合服务文档填写，保存前建议先测连通性。

---

## 启用与保存

1. 在左侧列表打开插件开关（立即改 registry/预设启用状态）
2. 在右侧「配置」改参数
3. 点 **保存配置** 写入租户配置

仅开开关未保存配置时，部分字段仍可能是默认值。日志页可核对最近变更（操作人、前后值）。
